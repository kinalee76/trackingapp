# 26. 개선: "현재 위치로 이동" 버튼 아이콘을 더 귀엽게, 크기 축소

## 요청

Phase 25에서 추가한 "현재 위치로 이동" 버튼의 아이콘을 조금 더 귀여운 모양으로 바꾸고, 크기를 약 50% 줄여달라는 요청.

## 구현 및 트러블슈팅

`MapScreen.tsx`에서 버튼 크기를 48px → 24px로 줄이고, 아이콘을 파란 크로스헤어에서 웃는 얼굴의 위치 핀(파란 teardrop + 흰 얼굴 + 눈 2개 + 미소)으로 교체했다.

최초 적용 후 실기기로 확인하니 두 가지 문제가 동시에 발생했다:
1. 버튼이 원형이 아니라 가로로 찌그러진 타원형으로 렌더링됨 (`uiautomator dump`로 확인한 실제 bounds가 105×66px — 정사각형이어야 할 24×24 버튼이 가로세로 비율 1.59:1).
2. 버튼 안의 SVG 아이콘이 전혀 보이지 않음 (흰색/회색의 빈 타원만 존재).

원인은 하나였다: Android WebView가 `<button>` 엘리먹트에 기본 네이티브 외형(`-webkit-appearance`)을 적용하는데, 이 네이티브 버튼 위젯은 자체적으로 비대칭 패딩을 추가하고 콘텐츠 위에 자체 배경/페인트 레이어를 그린다. 기존 코드는 `border: 'none'`만 지정했을 뿐 `-webkit-appearance`를 끄지 않았기 때문에, `width:24, height:24`로 지정한 content-box가 네이티브 위젯의 패딩만큼 더 커지면서 비정사각형이 되고, 네이티브 위젯의 자체 페인트가 내부 SVG를 가려버린 것으로 보인다.

수정: 버튼 스타일에 `WebkitAppearance: 'none'`, `appearance: 'none'`, `padding: 0`, `margin: 0`, `lineHeight: 0`, `boxSizing: 'border-box'`를 명시적으로 추가해 네이티브 외형을 완전히 제거. 아이콘 자체도 24px 버튼 안에서 더 잘 보이도록 14px→16px로 살짝 키움.

## 검증

실기기에서 확인:
- `uiautomator dump` 기준 버튼 bounds가 `[973,1997][1039,2063]` (66×66px, 완전한 정사각형)로 수정됨.
- 스크린샷을 크롭·확대해 확인한 결과, 흰색 원형 배경 위에 파란 웃는 얼굴 위치 핀 아이콘이 선명하게 보임.
- 기능 테스트: 지도를 다른 위치로 스와이프해서 이동 → 버튼 탭 → 지도가 정확히 현재 위치(파란 점) 중심으로 복귀함을 확인.
