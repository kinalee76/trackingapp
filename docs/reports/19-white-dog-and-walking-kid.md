# 19. 변경: 재생 마커를 흰둥이로, 추적 중 현재 위치를 걷는 아이 아이콘으로

## 요청

1. 재생 마커의 강아지를 "흰둥이"(흰 강아지)로 바꿔달라는 요청.
2. 추적 중 움직이는 "현재 위치" 포인트를 "짱구가 걷는 아이콘"으로 바꿔달라는 요청.

## 저작권 관련 안내 (요청 2에 대해)

"짱구"(크레용 신짱의 주인공)는 원작자/배급사가 저작권을 보유한 캐릭터라, 실제 캐릭터 디자인(스파이럴 앞머리, 눈썹 하나로 이어진 눈, 노란 셔츠+빨간 반바지 등 특징적 요소)을 그대로 복제해 앱에 넣는 것은 피했다. 대신 같은 목적("추적 중임을 보여주는 움직이는 캐릭터")을 살리는 **오리지널 디자인의 일반적인 걷는 아이 아이콘**으로 구현했다.

## 구현

### 흰둥이 (재생 마커)
`marker-icon.ts`의 `runningDogSvg()` 색상만 변경 — 몸통/머리/꼬리/배를 흰색·크림색(`#FBFAF7`, `#FFFFFF`, `#F7F5F0`) 계열로, 귀·다리 음영을 연한 회베이지(`#D8D2C4`, `#E4DFD3`)로. 애니메이션(다리 흔들림, 몸통 바운스, 꼬리·귀 움직임)과 형태(치비 비율, 큰 눈, 혀)는 Phase 18 디자인 그대로 유지.

### 걷는 아이 아이콘 (추적 중 현재 위치 마커)
`marker-icon.ts`에 `walkingKidSvg()` 신설 — 둥근 머리, 단순한 단발머리, 무지 색 상의(하늘색/청록 계열, 캐릭터 상징색인 노란색은 피함), 팔다리가 서로 번갈아 흔들리는 걷기 애니메이션. 강아지와 동일하게 순수 SVG+CSS만으로 구현.

`MapProvider.setCurrentLocationMarker`에 `options?: { tracking?: boolean }`을 추가:
- `tracking: true` → 걷는 아이 아이콘.
- `tracking: false`(또는 생략) → 기존의 단순 파란 점.
- 마커가 이미 존재할 때는 위치만 갱신하고, **tracking 값이 실제로 바뀔 때만** 아이콘을 교체한다(GPS 갱신마다 아이콘을 새로 그리면 걷기 애니메이션이 매번 0프레임부터 다시 시작해 뚝뚝 끊겨 보이기 때문).

`MapScreen.tsx`는 `tracking` 상태를 `trackingRef`에 미러링해 `watchPosition` 콜백(마운트 시 한 번만 구독되어 클로저가 고정됨)이 항상 최신 추적 상태를 읽어 `setCurrentLocationMarker(point, { tracking: trackingRef.current })`로 전달하도록 함.

## 검증

실기기에서 확인:
- 추적 시작 전: 기존과 동일한 파란 점.
- "추적 시작" 누르자마자: 즉시 걷는 아이 아이콘(둥근 얼굴, 청록 상의)으로 전환됨.
- "추적 중지": 다시 파란 점으로 정상 복귀.
- 기록 상세 화면에서 "재생": 마커가 흰색 강아지("흰둥이")로 정상 렌더링됨.
