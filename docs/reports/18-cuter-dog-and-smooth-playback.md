# 18. 개선: 강아지 아이콘 더 귀엽게 + 재생 이동을 부드럽게

## 요청

1. Phase 17에서 추가한 뛰는 강아지 아이콘을 더 귀엽게 바꿔달라는 요청.
2. "재생" 시 마커가 뚝뚝 끊어지며 이동하는데, 자연스럽게 흐르듯 움직이도록 개선해달라는 요청.

## 1) 강아지 아이콘 리디자인

`marker-icon.ts`의 `runningDogSvg()`를 단순 실루엣에서 치비(chibi) 비율로 다시 그림:
- 몸통보다 큰 동그란 머리, 반짝이는 큰 눈(하이라이트 점 포함), 발그레한 볼, 살랑거리는 처진 귀
- 혀를 내민 입, 크림색 배 무늬, 통통한 말린 꼬리
- 다리/귀/꼬리/몸통이 각자 다른 주기로 애니메이션되어 더 생동감 있게 움직임

## 2) 재생 애니메이션을 부드럽게

### 원인
`playback.ts`의 기존 `runPlayback()`은 `setInterval`로 `stepMs`마다 딱 한 번씩 마커를 **다음 GPS 포인트로 순간 이동**시키는 방식이었다. 연속된 GPS 포인트 사이 거리가 들쭉날쭉하다 보니(예: 정지해 있던 구간은 포인트가 촘촘하고, 빠르게 이동한 구간은 듬성듬성), 매 tick마다 캐릭터가 제자리에 멈춰있다가 갑자기 다음 위치로 "뚝" 튀는 것처럼 보였다.

### 수정
`runPlayback()`을 `requestAnimationFrame` 기반으로 재작성:
- 전체 재생 시간(`points.length * stepMs`)은 기존과 동일하게 유지.
- 매 프레임(~60fps)마다 현재 구간의 두 포인트 사이를 위경도 선형보간(lerp)한 위치로 `moveTo()` 호출 — 포인트 사이를 부드럽게 미끄러지듯 이동.
- `onStep`/`onDone` 콜백은 기존과 정확히 같은 횟수·같은 시점(포인트 하나당 한 번, `stepMs` 간격)에 그대로 호출되도록 유지 — `RoutePlayer`의 "n/전체" 카운터 표시와 일시정지 후 재생 재개(resume) 로직은 전혀 영향받지 않음.

## 검증

실기기의 5.39km 실제 기록으로 확인:
- 확대해서 본 강아지 아이콘이 이전보다 뚜렷하게 귀여워짐(큰 머리·눈·귀·꼬리) — 렌더링 깨짐 없음.
- 재생 → 일시정지(11/634) → 재생 재개(27/634로 정상 진행) — 콜백 횟수/인덱스 카운터가 기존과 동일하게 정상 동작.
- `adb logcat`에서 재생/보간 관련 에러 없음(기존부터 있던 무관한 "safe area CSS" 경고만 존재).
- 정적 스크린샷만으로는 매끄러움 자체를 증명하기 어렵지만, 코드 상으로 위치 갱신이 "틱당 1회 순간이동"에서 "프레임당(~60fps) 보간 이동"으로 바뀐 것은 확실하며, 이는 요청한 "끊김" 문제의 직접적 원인을 제거한 것.
