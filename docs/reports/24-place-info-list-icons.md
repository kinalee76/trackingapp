# 24. 기능 추가: 장소 정보 목록에서 사진/위치 항목 아이콘 구분

## 요청

"장소 정보" 목록에서 사진으로 저장된 항목과 일반 위치(체류 감지/수동 저장)로 저장된 항목을 아이콘으로 구분해달라는 요청.

## 구현

`PlaceInfoListScreen.tsx`에 각 항목의 `source`(`photo`/`stay`/`manual`)에 따라 제목 앞에 작은 인라인 SVG 아이콘을 추가:
- `source === 'photo'` → 보라색(`#7C3AED`) 카메라 아이콘 — 경로 상세 화면의 사진 촬영 위치 마커와 같은 색상으로 통일해, 앱 전체에서 "보라색 = 사진"이라는 시각적 일관성을 줌.
- 그 외(`stay`/`manual`, 둘 다 "위치 저장"이라는 공통점이 있어 하나로 묶음) → 파란색(`#2563EB`) 위치 핀 아이콘.

## 검증

실기기에서 장소 정보 목록을 확인 — 사진 촬영 항목(예: "11:22_정자")에는 보라색 카메라 아이콘, 수동 저장 항목(예: "2026-09-24_12:30_파동 앞산터널로")에는 파란색 핀 아이콘이 정상적으로 구분되어 표시됨. 항목 선택 시 상세 화면 진입도 정상 동작 확인.
