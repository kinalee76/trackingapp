# 25. 기능 추가: 지도에서 "현재 위치로 이동" 버튼

## 요청

추적 중(그리고 지도 화면 전반)에 지도를 이리저리 움직이다가 다시 내 현재 위치로 한 번에 돌아올 수 있는 기능 요청.

## 구현

`MapScreen.tsx`에 지도 우측 하단에 떠 있는 원형 버튼(흰 배경, 파란 크로스헤어 아이콘)을 추가:
- 이미 동작 중인 "현재 위치" `watchPosition` 콜백에서 매번 받는 좌표를 `currentPositionRef`에 캐싱.
- 버튼을 누르면 캐싱된 좌표로 `map.setCenter()` 즉시 호출. 아직 캐싱된 좌표가 없으면(막 권한을 허용한 직후 등) `Geolocation.getCurrentPosition()`으로 한 번 조회해 이동.
- 추적 여부와 무관하게 항상 사용 가능 — "현재 위치" 마커 자체가 이미 추적 여부와 무관하게 항상 표시되고 있어서(Phase 19), 버튼도 같은 조건으로 두는 것이 사용자 경험상 더 일관적이라고 판단함.

## 검증

실기기에서 확인: 추적 시작 → 지도를 다른 방향으로 스와이프해서 현재 위치 마커가 화면 가장자리로 밀려남 → 버튼 클릭 → 지도가 정확히 현재 위치(병아리 마커) 중심으로 즉시 복귀함.
