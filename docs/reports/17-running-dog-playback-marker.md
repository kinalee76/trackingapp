# 17. 기능 추가: 경로 재생 마커를 뛰어가는 강아지 아이콘으로 교체

## 요청

"재생"을 누르면 경로를 따라 움직이는 기본 마커를, 귀엽게 뛰어가는 강아지 애니메이션으로 교체해달라는 요청.

## 구현

외부 GIF/이미지 파일 없이, 인라인 SVG + CSS `@keyframes`만으로 뛰는 동작을 구현:
- `marker-icon.ts`에 `runningDogSvg()` 추가 — 몸통(타원)·머리(원)·귀·꼬리·다리 2개로 구성된 측면 강아지 실루엣에, 다리는 서로 반대 방향으로 흔들리는 `dg-swing-a`/`dg-swing-b`, 몸통은 위아래로 살짝 튀는 `dg-bob`, 꼬리는 흔들리는 `dg-wag` 애니메이션을 CSS `<style>` 태그로 SVG 안에 직접 삽입.
- `<img>`/data URI로만 쓰이는 경우(카카오/구글의 `MarkerImage`/`icon.url`)에도 SVG 내부 CSS 애니메이션은 계속 재생된다 — HTML 콘텐츠로 직접 삽입하는 네이버와 마찬가지로 별도 처리 없이 세 지도 모두에서 동일하게 동작.
- `runningDogIconHtml()`(네이버용 인라인 콘텐츠)/`runningDogIconDataUri()`(카카오·구글용 data URI), 크기(`DOG_SIZE`)와 중심 앵커(`DOG_ANCHOR`, 기존 핀과 달리 위치를 가리키는 뾰족한 끝이 없으므로 정중앙 기준)를 함께 export.
- 세 `MapProvider` 어댑터의 `animatePlayback()`에서 기존에 아이콘 없이 만들던 기본 마커를, 강아지 아이콘을 지정한 마커로 교체.

## 검증

실기기에서 5.39km 실제 기록을 열어 "재생" 실행 — 강아지 모양 마커가 시작 지점 근처에 나타나 경로를 따라 이동함을 확인(재생 인덱스 6/634 → 53/634로 정상 진행). 정적 스크린샷으로는 애니메이션(다리 흔들림) 자체까지는 확인이 어렵지만, 아이콘이 깨지지 않고 올바른 모양·크기·위치로 렌더링되며 경로를 따라 이동하는 것은 확인함.
