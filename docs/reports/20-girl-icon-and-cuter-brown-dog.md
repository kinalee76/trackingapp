# 20. 변경: 걷는 아이를 여자아이로, 흰둥이를 더 귀여운 갈색 댕댕이로

## 요청

1. "걷는 아이"(추적 중 현재 위치 마커)를 귀여운 여자아이로.
2. "흰둥이"(재생 마커)를 다시 갈색으로, 더 귀엽게.

## 구현

### 갈색 댕댕이 (재생 마커)
`marker-icon.ts`의 `runningDogSvg()` 색상을 흰색 계열에서 진한 캐러멜·초콜릿 브라운 계열(`#D89150` 몸통, `#7A4A24` 귀·다리, `#C1793F` 꼬리)로 되돌리면서, Phase 18/19보다 한 단계 더 귀엽게 다듬음: 눈을 좀 더 크고 진하게(`#241207`), 하이라이트를 2개로 늘려 반짝임 강화, 볼터치를 더 진하고 크게.

### 여자아이 아이콘 (추적 중 현재 위치 마커)
`marker-icon.ts`의 `walkingKidSvg()`를 여자아이로 명확히 알아볼 수 있게 다시 그림:
- 양 갈래 머리(트윈테일) — 머리 옆 작은 번(bun) + 아래로 늘어진 머리채, 걸을 때 다리/팔과 함께 살짝 흔들리는 애니메이션 추가
- 오른쪽 머리에 리본(나비 모양) 장식
- 바지 대신 아래로 퍼지는 원피스(치마) 형태, 허리~밑단으로 갈수록 넓어지는 두 겹 색상(연한 핑크 상의 + 진한 핑크 치마)
- 속눈썹, 눈 하이라이트 추가로 표정을 더 또렷하고 귀엽게

여전히 특정 저작권 캐릭터를 모사하지 않은 오리지널 디자인.

## 검증

실기기에서 확인:
- 추적 시작 시 여자아이 아이콘(트윈테일+리본+원피스)으로 정상 전환, 추적 중지 시 파란 점으로 복귀.
- 경로 상세 "재생" 시 마커가 갈색 강아지로 정상 렌더링.
